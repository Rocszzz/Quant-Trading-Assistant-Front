# Quant-Trading-Assistant-Front

Quant Trading Assistant 前端项目，基于 Vue 3、Vite、TypeScript、Element Plus、Pinia、Vue Router 和 Axios 初始化。

## 目录结构

```text
src
├── components
│   └── MetricCard.vue
├── layouts
│   └── MainLayout.vue
├── router
│   └── index.ts
├── stores
│   └── user.ts
├── styles
│   └── index.css
├── utils
│   └── request.ts
├── views
│   ├── Backtest.vue
│   ├── Dashboard.vue
│   ├── Login.vue
│   ├── PaperTrading.vue
│   ├── RiskControl.vue
│   ├── Settings.vue
│   ├── Strategy.vue
│   └── Watchlist.vue
├── App.vue
├── main.ts
└── vite-env.d.ts
```

## 常用命令

```bash
npm install
npm run dev
npm run build
```
